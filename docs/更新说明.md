# 更新说明（本二开项目 vs 开源轻页）

本文档对照本项目的 fork 上游 —— [duckeaty/legado3-harmony](https://github.com/duckeaty/legado3-harmony)（开源轻页，上游基线提交 `e41f614c`，2026-09-17），逐项梳理本二开项目（`pojianhuaidao/legado3-harmony`）与上游的所有区别，涵盖包名与版本、已实现功能、UI 改动、内置资源、构建与发布方式等。

## 1. 包名与版本差异

| 项目 | 上游（开源轻页） | 本二开项目 |
| --- | --- | --- |
| 应用包名 | `io.legado.read` | `lagado.hm.app` |
| 版本号 | 固定 `3.9.907`（versionCode `390907`） | CI 动态生成 `1.MMDD.NN`（versionCode 由 `MMDDNN` 前补一位 `1` 构成，如 `1.1007.02 → 1100702`；同日构建序号 `.01/.02/...` 递增，跨日重置） |
| 出包文件名 | DevEco 本地签名产物 | CI 统一产出 unsigned HAP：`lagado.hm.app_<versionName>.hap`，上传 GitHub Release，`build-N` 递增、不删除旧 Release |
| 图标配置 | 单图标 | `alternateIcons` 多套应用图标（墨染/极简线稿/夜霓虹/像素复古/主题蓝/暖纸/森林雾/墨染主题/霓虹主题/暖书） |

## 2. 相对上游的新增功能

### 2.1 订阅/发现模块（整体新增）
- 新增订阅收藏体系：`RssSource` 数据模型、`RssSourcesDataSources`、`RssSourcesUtils`、`SubscriptionTab`（收藏分组、最近使用、长按菜单）。
- 新增页面：`SubscriptionIndex`（订阅首页）、`SubscriptionImport`（订阅导入）、`SubscriptionWebView`（订阅内页，三点菜单）。
- 收藏项长按可修改收藏名及网址；进入订阅页后在“三点”菜单处也可修改收藏名。
- 收藏分组支持自行变更（新增/修改分组，增改分组名）。
- 最近使用记录支持删除（单条长按删除、一键清空）。

### 2.2 书架搜索与源仓库
- 书架搜索支持本地/在线切换，搜索结果可直接进入详情/目录/阅读。
- 书源仓库一键导入（基于书架搜索的源仓库入口）。

### 2.3 阅读与朗读增强
- AI 分角色朗读：`RoleTagger` / `RoleTtsDriver` 支持多厂商 LLM 标注角色并链式分音色朗读，集成至 `TtsSettings`、`SystemTtsReader`、`ReadBook`。
- 阅读统计：新增 `ReadStatistics` 页面。

### 2.4 广告过滤
- 新增 `AdBlocker` / `AdRuleUpdater`：广告规则动态更新与过滤。

### 2.5 超时与健壮性
- 新增 `TimeoutHelper`：书源搜索/发现请求超时保护（配合书山探索空态修复）。

### 2.6 构建与发布
- 新增 GitHub Actions `build-hap.yml`：自动 assembleHap、动态版本号、出 unsigned HAP、发布 Release。
- 新增 `scripts/build_sidecar.ps1`。

## 5. 相对上游的删除/移除项

- **华为账号与云同步体系**：`account/AccountSessionStore`、`CloudSyncChangeTracker`、`CloudSyncCoordinator`、`CloudSyncModels`、`CloudSyncSettingsStore`、`CloudSyncStateStore`、`CloudTtsClient`、`HuaweiAccountService`、页面 `AccountCenter`、`DataSync`、`SyncDevices` 全部移除。
- **华为 AppGallery 类型桩**：`types/AppGalleryKit.d.ts` 移除。
- **原 HTTP TTS 管理页/读取器**：`CustomTtsVoiceManager`、`HttpTtsReader` 移除（音色管理整合进 `TtsSettings`）。
- **静态图标脚本**：`scripts/apply_static_icon.py` 移除（图标能力迁移到运行时多图标切换）。

## 6. 其他主要修改

- **书源/搜索/发现链路**：`BookSourceHeaderRuntime`、`BookSourceLoginWebRuntime`、`BookSourceStageWebRuntime`、`ExploreCoordinator`、`ExploreReadingValidator`、`SearchCoordinator`、`AnalyzeUrl`、`HttpClient` 等大量修复（含书山探索空态根因修复、登录脚本语法修复、请求健壮性）。
- **阅读器**：`ReadBook`（分角色朗读、眼动翻页、V2 分页等）、`ReaderReplaceRules` / `ReaderReplaceRuleStore`（替换净化规则）、`ReaderSettingsStore`、`BookChapterList`。
- **数据层**：`AppDatabase` 新增收藏历史/分组/删除方法（含 `clearRssSourcesHistory` 等）。
- **局域网阅读**：`LanReaderServer` 持续增强。
- **入口**：`EntryAbility` 启动链路优化（延迟初始化、书架封面/主题/朗读配置等）。
- **页面路由与配置**：`main_pages.json`（新增订阅等页面）、`shortcuts_config.json`、`AppScope/app.json5`、`build-profile.json5`、`oh-package.json5`、`quickjs/BuildProfile.ets`、`entry/oh_modules/@devzeng/quickjs/BuildProfile.ets`。
